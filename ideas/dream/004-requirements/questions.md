# Requirements: Questions

**Layer:** 004, Requirements
**Status:** Draft

These requirements apply to [questions](../003-process/questions.md), which Analyze forms when evidence is ambiguous or conflicting.

---

**QST-1. Every question cites the evidence that raised it.** This follows from principle 7 and from the definition of a question in layer 002.

- Each question links to the evidence whose ambiguity or conflict it asks about.
- In the layer 001 scenario about conflicting evidence, the question cites both sessions.

**QST-2. Only Analyze forms questions.** Layer 003 states that Collect and Link never form one.

- Every question was formed by Analyze.

**QST-3. The same question is never asked twice.** Layer 002 defines two questions as the same when they ask about the same ambiguity or conflict in the same evidence.

- A question judged the same as an open, answered, or withdrawn question is never put to the user again.

**QST-4. Open questions are ranked by how many findings wait on them.** Layer 003 sets this order, and it allows any number of questions to be open at once.

- Open questions are put to the user in order of the number of findings that wait on each one, with the most first.

**QST-5. Every answer and withdrawal is kept.** Layer 003 defines both, and principle 10 keeps them in the history.

- An answer is recorded as user input and joins the evidence.
- A withdrawn question records the evidence that settled it.
- Answered and withdrawn questions stay in the history.
