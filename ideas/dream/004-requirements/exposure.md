# Requirements: Exposure

**Layer:** 004, Requirements
**Status:** Draft

These requirements apply to [exposure](../003-process/exposure.md), which is how published outputs reach agents through direct access.

---

**EXP-1. Only current versions are offered as current knowledge.** Layer 003 sets this rule for direct access.

- No superseded version is offered as current knowledge.
- No retired output is offered as current knowledge.

**EXP-2. An output reaches an agent's work only where its applied scopes cover that work.** This follows from principle 9, and the overview gives "covers" its meaning.

- An output whose applied scopes do not cover an agent's work is never offered to that agent through direct access.
- An output whose applied scopes cover an agent's work is available to that agent through direct access (layer 003, direct access).
- An output's proposed scopes have no effect on where it is offered.

**EXP-3. Every output is given with its origins.** This follows from principle 9.

- Each output offered through direct access carries the origin of each applied scope through which it reached the agent.

**EXP-4. Direct access changes nothing in Archon.** Layer 003 sets this rule.

- Reading outputs through direct access leaves every output and all internal knowledge unchanged.
- What an agent does after reading an output reaches Archon only as facts that Collect records.

**EXP-5. Agents reach internal knowledge only through outputs.** This follows from the definition of internal knowledge in layer 002.

- Direct access offers no claim, finding, question, or other internal knowledge.
- Direct access offers only the current versions of published outputs.
