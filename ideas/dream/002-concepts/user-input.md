# Concept: User input

**Layer:** 002, Concepts
**Status:** Proposed

User input is anything the user states. It takes the following forms.

- A note given to Archon directly (principle 6).
- An answer to a [question](question.md) (principle 7).
- An edit the user makes to a [change](change.md) while deciding on it.
- A statement or correction made during a [session](session.md).

Notes, answers, and edits are kept as [records](record.md), exactly as written. Statements made during a session are already events in a session record. User input is [evidence](evidence.md), and it is weighed alongside recorded experience. It says how the user means things to work, which can differ from what the record shows, so it is always kept identifiable as user input.

## Sameness

Two pieces of user input are the same when they are the same record. The same words given twice are two pieces of user input.
