# Concept: Source

**Layer:** 002, Concepts
**Status:** Proposed

A source is the starting point from which a [claim](claim.md) entered the record or Archon's knowledge. It can be a machine-produced [observation](observation.md), a piece of [user input](user-input.md), a piece of [existing knowledge](existing-knowledge.md), or an agent [inference](inference.md) that traces back to nothing earlier.

## Sameness

Two occurrences of a claim share a source when the record shows a path from each back to the same starting point, such as the same file, instruction, memory, earlier session, or parent agent. Occurrences with no shared path come from independent sources.
