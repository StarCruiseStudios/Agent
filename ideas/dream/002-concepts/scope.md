# Concept: Scope

**Layer:** 002, Concepts
**Status:** Proposed

A scope is a [tag](tag.md) on an [output](output.md) that names where its knowledge applies. One output can carry any number of scopes, and each scope carries its own [origin](origin.md). Each output has two sets of scopes.

- **Proposed scopes** are the tags that a [change](change.md) records as places where the knowledge could apply.
- **Applied scopes** are the tags applied when the change is approved. An output reaches an agent's work only through its applied scopes (principle 9).

## Sameness

Two scopes are the same when they are the same tag.
