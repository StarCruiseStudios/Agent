# Concept: Origin

**Layer:** 002, Concepts
**Status:** Proposed

An origin says whether knowledge is a user preference or generalizable, as layer 001 defines the two labels. Each [scope](scope.md) on an [output](output.md) carries its own origin, so one output can be a user preference in one scope and generalizable in another. Because origin travels with the scope, a user preference is never presented as a general rule (principle 9).
