# Concept: Output

**Layer:** 002, Concepts
**Status:** Proposed

An output is a memory, a practice, or a skill, as layer 001 defines them in its scope file. It is what agents load. An output keeps one identity through all of its [versions](version.md), and it carries a set of [scopes](scope.md), each with an [origin](origin.md).

Memory is descriptive, and practices and skills are prescriptive, so the two kinds of knowledge are kept distinct (principle 8). [Existing knowledge](existing-knowledge.md) counts as outputs that are already published.

## Sameness

Two outputs are the same when they are versions of the same output. Changing an output's content, its scopes, or the origin of a scope revises the output and never creates a new one.
