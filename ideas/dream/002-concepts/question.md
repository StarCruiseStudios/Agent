# Concept: Question

**Layer:** 002, Concepts
**Status:** Proposed

A question is something Archon asks the user when the evidence is ambiguous or conflicting (principle 7). A question cites the evidence that raised it. Its answer is [user input](user-input.md), and it joins the evidence. A question is part of how Archon reaches a decision, and it is never an [output](output.md).

## Sameness

Two questions are the same when they ask about the same ambiguity or conflict in the same evidence.
