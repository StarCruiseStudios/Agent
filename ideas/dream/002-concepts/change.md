# Concept: Change

**Layer:** 002, Concepts
**Status:** Proposed

A change is one proposed alteration to what agents load. Each change carries its [evidence](evidence.md) (principle 2), and it is decided on its own. A change is one of the following kinds.

| Kind | What it does |
|---|---|
| **Addition** | Adds a new [output](output.md), with its proposed [scopes](scope.md). |
| **Revision** | Replaces an output's current [version](version.md) with a new one. Changing an output's content, its scopes, or the origin of a scope is a revision. Returning an output to an earlier version is also a revision. |
| **Retirement** | Withdraws an output from use by agents. Its versions and evidence stay in the history. |
| **Publication to a project** | Places one approved output into one location in a project's own files or an agent's built-in rules, such as a hand-written instruction file. |

A publication to a project is a change of its own because it alters what agents load (principle 12), even though the output it places is already approved.

## Sameness

Whether a newly drafted change is the same as an earlier one, such as a rejected change that is proposed again, is a judgment. The judgment is an inference, so it carries its own evidence and can be revised.
