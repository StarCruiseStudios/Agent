# Concept: Version

**Layer:** 002, Concepts
**Status:** Proposed

A version is the state of one [output](output.md) that one approved [change](change.md) made, or that one record of [existing knowledge](existing-knowledge.md) captured: its content, its applied [scopes](scope.md), and their [origins](origin.md). An output has at most one current version. Earlier versions are kept, so each output can be returned to an earlier version on its own (principle 14). A version that is no longer current, because a later version replaced it or the approval that made it current was taken back, is **superseded**, and it stays in the history (principle 10).

## Sameness

Two versions are the same when they belong to the same output and come from the same change or the same record.
