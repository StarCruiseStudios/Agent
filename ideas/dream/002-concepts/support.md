# Concept: Support

**Layer:** 002, Concepts
**Status:** Proposed

Support is how well the [evidence](evidence.md) backs a [claim](claim.md). It is counted in independent [sources](source.md), so repeated occurrences that share a source add none (principle 5).

A claim the user states has the same standing as a claim backed by an observation, whether it concerns the user's preferences or how a project or tool behaves. It stays identifiable as [user input](user-input.md), because it says how the user means the work to go, and that can differ from how a code base actually behaves.
