# Overview

* [Oracle](/wiki/areas/engineering-toolkits/systems/oracle/overview.md) - Oracle is a set of user interface toolkits and a style guide for desktop, mobile, and terminal applications.

# Containers

* [Oracle TypeScript Toolkit](/wiki/areas/engineering-toolkits/systems/oracle/containers/typescript-toolkit/overview.md) - The Oracle TypeScript toolkit is an npm workspace of packages for building React, Electron, and Ink applications.
* [Oracle Kotlin Toolkit](/wiki/areas/engineering-toolkits/systems/oracle/containers/kotlin-toolkit/overview.md) - The Oracle Kotlin toolkit is a Gradle build of Compose Multiplatform libraries with desktop, Android, and iOS example hosts.
* [Oracle Style Guide](/wiki/areas/engineering-toolkits/systems/oracle/containers/style-guide/overview.md) - The Oracle style guide is the reference for Oracle interface design, published as HTML and Markdown pages with a reader application and an agent instruction pack.
