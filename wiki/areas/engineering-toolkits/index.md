# Overview

* [Engineering Toolkits](/wiki/areas/engineering-toolkits/overview.md) - The engineering toolkits area groups reusable toolkits that other projects build on.

# Systems

* [Atlas](/wiki/areas/engineering-toolkits/systems/atlas/overview.md) - Atlas is a toolkit for understanding and enforcing the architecture of a software project.
* [Oracle](/wiki/areas/engineering-toolkits/systems/oracle/overview.md) - Oracle is a set of user interface toolkits and a style guide for desktop, mobile, and terminal applications.
