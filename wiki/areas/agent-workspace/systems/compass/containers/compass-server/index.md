# Overview

* [Compass Server](/wiki/areas/agent-workspace/systems/compass/containers/compass-server/overview.md) - The Compass server is a Node.js process that serves read-only MCP tools over standard input and output.

# Components

* [Catalog](/wiki/areas/agent-workspace/systems/compass/containers/compass-server/components/catalog.md) - The catalog component discovers instruction packs across catalog directories, applies first-definition-wins and case-collision rules, and maps every failure to a stable error code or problem reason.

# Flows

* [Pack Discovery and Fetch](/wiki/areas/agent-workspace/systems/compass/containers/compass-server/flows/pack-discovery-and-fetch.md) - How a host or agent lists instruction packs, validates one, and fetches its instructions and skills from the Compass server.
