# Overview

* [Agent Workspace](/wiki/areas/agent-workspace/overview.md) - The agent workspace area groups the tools that support working with AI coding agents.

# Systems

* [Armory](/wiki/areas/agent-workspace/systems/armory/overview.md) - Armory is a package manager for modules of source code, built for agentic development.
* [Codex Commander](/wiki/areas/agent-workspace/systems/codex-commander/overview.md) - Codex Commander is the source package for 'Commander', a custom pet for Codex.
* [Compass](/wiki/areas/agent-workspace/systems/compass/overview.md) - Compass is a local MCP server that gives AI agents access to human-written instruction packs.
* [Overmind](/wiki/areas/agent-workspace/systems/overmind/overview.md) - Overmind coordinates work for AI agents on a local machine.
* [Skills Library](/wiki/areas/agent-workspace/systems/skills-library/overview.md) - The skills library is a folder of reusable agent skills, each a directory with a SKILL.md file.
* [Spec N' Roll](/wiki/areas/agent-workspace/systems/spec-n-roll/overview.md) - Spec N' Roll is a toolkit for spec-driven development with AI agents.
