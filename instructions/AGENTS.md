# Instruction library

The subfolders of this directory form a library of instruction sets. Each one is meant to be installed into other projects, where its contents become part of that project's agent instructions file (for example `AGENTS.md` or `CLAUDE.md`). The `install-instructions` skill performs that installation.

The files in these subfolders are source material, not guidance for this repository. Do not read them as instructions for your own work here, do not apply their rules to changes in this repository, and do not cite them as the conventions that govern it. Open them only when the task is to create, edit, review, or install an instruction set.

Write each instruction set so that it makes sense when copied into an unrelated project. Avoid references to this repository's layout, tooling, or other files.
